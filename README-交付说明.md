# 漫思茶 · 完整交付包（2026-10-24）

一句话介绍：**茶饮电商小程序 + Spring Boot 双服务后端 + LLM 智能导购 Agent**。在老电商系统（Spring Boot 2.6.13 / JDK 8）之上，以微服务方式叠加了一个 Agent 服务（Spring Boot 3.2.4 / JDK 17），支持自然语言「找茶 → 问茶 → 下单」，内置茶知识 RAG 检索、运营管理后台（15 个页面）。

## 二、快速跑起来（详细版见《代码详解与部署指南》第五部分）

1. **环境**：JDK 8 + JDK 17、Maven、MySQL 8、Redis、Nacos（2.3.x）、Node（构建前端用）、微信开发者工具
2. **建库**：MySQL 执行 `sql/db_tear-全量-2026-10-24.sql` 和 `sql/db_agent-全量-2026-10-24.sql`（记得 `--default-character-set=utf8mb4`）
3. **环境变量**：见下方第三节，最少配 `LLM_API_KEY` 和 `ADMIN_USERS` 两个
4. **启动顺序**：MySQL → Redis → Nacos（等 8848 起来）→ tearSpring(8080) → agent-service(8081)
5. **前端**：WeixinUniapp 目录参照 `build-mp.bat` 的流程构建（`UNI_INPUT_DIR` 指向工程根目录），产物导入微信开发者工具（游客模式 appid 已配好）
6. **验证**：打开 `http://127.0.0.1:8081/admin-login.html` 登后台，小程序端登录后下单走一圈

## 三、必须自行配置的环境变量（交付包里不含任何真实密钥）

| 变量 | 说明 |
|---|---|
| `LLM_API_KEY` | **必配**。OpenAI 兼容网关的 Key（任何兼容平台均可，如 DeepSeek 官方） |
| `LLM_BASE_URL` | 网关地址，默认 `https://api1.dshapi.icu/v1`，换平台改这里 |
| `LLM_CHAT_MODEL` | 模型名，默认 `deepseek-v4.1-flash`（后台「模型管理」页可在线切换） |
| `ADMIN_USERS` | **必配**。后台账号，格式 `admin:你的口令:admin,viewer:你的口令:viewer` |
| `DB_PASSWORD` | MySQL 密码（代码默认 123456，按你本机实际改） |
| `EMBED_API_KEY` | RAG 向量检索用（硅基流动 BGE-M3，免费额度即可；不配则检索自动降级为 BM25 关键词） |
| `JWT_TOKEN_KEY` | tearSpring 的 JWT 签名密钥（默认 dev 占位符，务必换） |
